## 👋 About

I'm a solutions engineer in London who builds end to end — from Chrome extensions and
full-stack web apps down to C++ and systems tooling. Most at home in TypeScript,
Python, Rust, C++ and Salesforce (Apex · LWC). I like taking an idea from nothing to
something people actually use, and I care about the details in between.

**Right now:** shipping data tooling for Salesforce, a terminal for exploring AI
coding sessions, and browser games in TypeScript.
