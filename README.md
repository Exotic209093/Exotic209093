<img src="./assets/header.svg" width="100%" alt="James C, solutions engineer in London. From Salesforce apps to Rust render engines. Now building Galacia Vault, Docify and WaveLink." />

I'm a solutions engineer in London. Day to day that's Salesforce (Apex, LWC, integrations),
but the projects I care about most run the whole stack: Chrome extensions, Electron apps,
browser games, a document render engine in Rust, and C++ game-server plugins.
I like taking something from nothing to a thing people actually use.

## Now

- **[Galacia](https://galacia.app)** is a company I'm building. The first product, [Galacia Vault](https://galacia.app/galacia-vault/), is a Salesforce file workspace where customers keep files in cloud storage they own. Source is private while it moves through release validation.
- **Docify** is a native HTML/CSS render engine in Rust. One layout pass, no browser, out to PDF (tagged, PDF/UA and PDF/A), PNG, SVG and DOCX. Private for now.
- **[WaveLink](https://github.com/Exotic209093/WaveLink)** is live on the [Chrome Web Store](https://chromewebstore.google.com/detail/wavelink/ccknhhibbedolfnbgnenomdohlmojblo): SOQL to CSV/JSON/Excel/XML, Bulk API imports, scheduled snapshots and cross-org migrations with ID remapping.
